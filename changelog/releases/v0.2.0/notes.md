## 🔧 Changes

### Compact footer service-tier indicator

The `pi-fancy-footer` widget now shows a single `⚡` whenever a service tier is active instead of spelling out the tier name.

For example, both `priority` and `flex` now appear as:

```text
⚡
```

This keeps the footer compact while preserving the active-tier indicator.
